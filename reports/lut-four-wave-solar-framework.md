# 四波长实时框架：太阳简化误差与最终默认

**当前默认更新**：用户看过比较后接受纯平行光误差，已将 `DEFAULT_SUN_MODEL` 改为 `Parallel`。运行时一次散射使用太阳中心的一个平行光方向；可见太阳圆盘继续按真实角半径单独绘制。四波长、固定 MS 源、256×256 SkyView、128 步和资源预算保持不变。MS 与地面反射数据继续来自原有限太阳的冻结参考，本次没有改成另一套重新收敛的平行太阳大气解。下文保留此前四点候选的完整误差与选择记录；其中“四点默认”已被本段更新取代。

2026-09-18。纯平行光已经量化。当前将 **四波长 + 固定各向异性 MS 源 + 256×256 SkyView + 128 步 + 4 点太阳圆盘积分** 固定为 demo 默认；没有继续扩展自适应太阳采样分支，也没有改参考烘焙器或重新搜索波长。

单点平行光约 0.63 ms，4 点约 1.1 ms，原 16 点约 9–10 ms。4 点的太阳模型误差明显小于单点，并低于当前主要的 SkyView 插值误差；因此保留这约 0.45 ms 的开销。每个“点”是太阳圆盘上的一个平行光方向，四个方向等权，独立于四个光谱波长。

## 误差对照

## 连续运动与步数

增加 54 帧检查：12 km 地影场景太阳间隔 0.01° 的 21 帧，以及日落近景太阳间隔 0.05° 的 33 帧。两种模型经过相同的 SkyView 映射，以 64 点 SkyView 为对照。

|扫描|纯平行光最大帧 P95|4 点最大帧 P95|4 点所有像素最大|
|---|---:|---:|---:|
|12 km 地影|2.867%|0.501%|1.026%|
|日落近景|2.417%|0.088%|0.346%|

相邻帧的“新增误差残差”变化 P95，4 点地影扫描最高 0.099%，日落扫描最高 0.114%；纯平行光分别为 0.259%、0.374%。这只是有限的连续扫描，不是任意方向与太阳速度的无伪影保证。

八个难例另外比较了 512 步。4 点相对 64 点的 P95 最高仍约 0.28%；64 点自身从 128 到 512 步的差异 P95 最高约 0.24%。据此继续使用默认 128 步，保留 512 步作为诊断。

有限线段也检查了 4 点太阳：六种情形包含昼夜、地面、薄边和非共面方向，512 步下 `L_ac = L_ab + T_ab L_bc` 的亮度相对差最大约 0.000321%，透射率绝对差最大约 2.45e-6；真空仍为 L=0、T=1。这不代表已经完成 froxel 雾效集成。

## 固定的算法与数据边界

1. **离线资源**：由冻结 v6 参考合成 450、510、580、650 nm 的各向异性 MS 源、透射率、介质与相位数据。大气和地面反照率固定。
2. **加载时**：将低空 SH 展开为固定的 4D 方向源纹理；高空保留六项瑞利 SH。只做一次，随后释放低空完整 SH。
3. **太阳高度或海拔变化时**：在 256×256 SkyView 中做四波长、128 步视线积分。一次散射固定使用四个等权太阳方向，角半径约为太阳半径的 1/√2；小角度下匹配均匀圆盘的二阶矩。多重散射查询固定源项。
4. **相机旋转、FOV、太阳方位变化时**：复用 SkyView，只重投影。可见太阳盘按真实角半径和该显示像素的透射率独立求值。
5. **颜色与扩展**：积分后转 Rec.2020，SkyView 保持 f32。体积雾继续复用同一局部四波长源和有限线段 L/T；二维 SkyView 不替代有限距离传输，RGB 材质的透射近似仍须单独明确。

默认没有按太阳角度切换采样数，也没有时域累积。避免另引入切换阈值、历史缓存或拖影。当前各模型通过独立 shader 编译，四点路径不携带十六点路径的大数组和循环成本。

常驻 LUT 含 SkyView 保持 **16,769,248 B = 15.992 MiB**（十进制 16.769 MB），初次展开临时数据与屏幕缓冲另计。磁盘资源、MS 分配和 SkyView 分辨率均未改变。

## 最终性能与已有误差

RTX 4090 / Vulkan，同场景 512×384，GPU timestamp，包含 demo 的显示 pass：太阳高度变化 **9.70 → 1.09 ms**；相机变化 **0.013 ms**。独立天空 benchmark 的 4K 重投影约 **0.148 ms**，4K 太阳高度变化约 **1.39 ms**。不同测试的 GPU 频率/开销有波动；这些不是整个应用的帧时保证。

本报告的低误差是**太阳模型新增误差**。四波长、源项压缩、SkyView 插值、原参考偏差仍然存在。新增的 4° 太阳近景检查中，完整 SkyView 相对 64 点逐像素积分的 P95 最高约 **2.79%**（太阳高度 5°），明显高于该场景四点太阳自身约 0.023% 的误差。此轮不继续改网格，保留这个可测的局限；继续增加太阳积分点数已经不是主要收益方向。

## 复现与验收

```powershell
python scripts/make_four_wave_sun_queries.py
cargo run --release -p sky-atmosphere-lut --example validate_four_wave_gpu -- out/four_wave_source_v1 --queries out/four_wave_sun_v1/queries.json --out out/four_wave_sun_v1/finite4_sky --steps 128 --mode sky --sun-model finite4
cargo run --release -p sky-atmosphere-lut --example profile_four_wave_cost
cargo run --release -p sky-atmosphere-lut --example benchmark_four_wave_cache -- --out out/four_wave_sun_v1/benchmark.json
cargo run --release -p sky-atmosphere-lut --example validate_four_wave_segments -- --sun-model finite4 --out out/four_wave_sun_v1/segments.json
cargo run --release -p sky-realtime-demo -- --experiment four-wave --lut-budget-mib 16
```

比较模式用 `--sun-model parallel / phase-averaged / finite4 / finite16 / finite64`；`--mode source` 隔离直接积分，`--mode sky` 包含缓存。原逐像素 `Renderer::new` 保持 16 点诊断默认，生产 `CachedRenderer::new` 固定 4 点；有限线段调用可显式传 `SunModel::Finite4`。

已通过所有太阳模型的 Naga 校验、release 编译、实际 GPU 图像检查、十种缓存失效检查（MS 展开始终一次）和上述六种有限线段检查。产物：

- `out/four_wave_sun_v1/visual/index.html`：43 场景比较页，平行光误差图黄色=5%，4 点误差图黄色=1%。
- `summary.json`：静态、运动扫描、步数检查，以及太阳盘内外和完整缓存误差。
- `cost_ablation.json`、`benchmark.json`、`noon.json`：计时与测试范围。
- `segments.json`、`invalidation.json`：线段和缓存验收。

该框架作为后续纹理布局、压缩和 froxel 开发的基线。参考求解、实时重建和最终显示的职责已经分开，后续改动可在固定误差集上对照。
