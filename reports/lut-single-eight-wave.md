# 运行时改用优化 8 波长，41 波段保留为离线参考

2026-09-18。按用户要求，后续运行时基线改为已有 demo 的 **8 波长、两组 vec4**；上一轮 41 波段单次积分仅用于测量误差。完成了 CPU 对照及固定介质参数的预计算导出。本轮没有 GPU 计算，也没有替换 demo 的渲染路径。

## 复用的配置

直接引用 `sky-unreal-atmosphere-8wave::params` 中的波长和搜索权重：

|波长 / nm|410|440|480|520|540|580|610|670|
|---|---:|---:|---:|---:|---:|---:|---:|---:|
|积分权重 / nm|92.825735|20.873265|60.113315|20.884022|27.544867|43.543118|30.491347|113.724330|

颜色转换直接读取现有 WGSL 的光谱→Rec.2020 矩阵及完整参考太阳白点→D65 矩阵。没有重新中和 8 个太阳样本。参考文件的值是波段积分量，先除以对应带宽再应用稀疏积分权重，防止重复乘 10 nm。矩阵本身已经包含搜索权重，运行时不能再乘一次。

物理消光、散射剖面及实测相位仍来自当前冻结参考，包括四种气溶胶及其层结；本次只隔离“41→8 波长”的变化。另一个 demo 的三物种简化、解析剖面和各向同性多重散射近似没有混入本实验。这不是重新测量整个 UE demo。

计算路径：

```
CPU 离线：41 波段参考 → 多重散射 → Rec.2020 主表
CPU 预计算：8 个波长的介质系数、相位、太阳光谱和最终颜色矩阵
GPU 目标：两组 vec4 积分单次散射 → 转 Rec.2020 → 加多重散射主表
```

仅最终颜色转换使用 3 通道；消光指数、相位和单次散射积分保持 8 个光谱通道。41 波段不进入拟议的运行时循环。

## 新增的光谱误差

复用上一轮 768 个确定性查询及其完整光谱对照；其中 677 个教师 RGB 长度 >1e-8。每个波长都使用相同几何、介质、256 步和有限太阳盘 4×16 样本，因此下表单独测量光谱减少的影响。

指标为 `||S1_8 − S1_41|| / ||L_reference_total||` 的 **P95**；包含天空和地面方向，不是除以可能接近零的单次散射。这是小样本筛查，不能当作大数据集 P99 或无偏物理解误差。

|12 km|1.561%|

## 预计算与容量

已导出 `out/lut_single_multi_eight_wave/runtime_parameters/`：

- 50 个高度节点，介质系数按 `[height][2 groups][6 coefficients][vec4]` 保存：消光、Rayleigh、四种气溶胶散射；运行时只需插值。
- 相位按 `[2 groups][4 species][1024 bins][vec4]` 保存；继续使用已有立方根相位坐标。
- 太阳每 nm 辐照度和含权重、白平衡的颜色矩阵保存到 `parameters.json`。
- 以上 f32 二进制参数共 **140,872 B**。这是可复用的固定介质参数包，尚不含透射表和多重散射主表，也没有 GPU 接入。

新的天空分支拟议预算：

|载荷|配置|字节|
|---|---|---:|
|多重散射 Rec.2020 主表|32×32×65×33×3×bf16|13,178,880|
|8 波长太阳透射表|两组 128×1024 RGBA16F|2,097,152|
|原相位与预卷积相位|2×8×4×1024×f32|262,144|
|地面辐照度|8×1024×f32|32,768|
|介质剖面、常数、映射及对齐预留|含实际 9,800 B 高度/剖面数据|131,072|
|合计|—|**15,702,016 B**|

两个 vec4 透射表比运行时每波长组合六种介质柱密度更直接；这里优先采用 demo 式的预计算路径。**透射表减小分辨率、RGBA16F 量化、有限太阳盘相位预卷积尚未测量**，15.70 MB 是预算方案，不是已完成并验证的资源包；也不含 sky-view / 体积缓存。

光谱通道数由 41 降为 8，相关算术约降为原来的 **19.5%**，但这不是 GPU 帧时快 5.1 倍的实测结论。射线几何可由两组 vec4 共享，天空结果应缓存到 sky-view。本轮依然保留 64 个太阳盘样本，相关成本必须通过预卷积与地影半影采样另行降低。

8 波长是运行时约束。面向视距雾和体积光，后续若采用多重散射局部源项，也应在这 8 个通道下评估，最后才转 RGB。仅有 RGB 天空边界余量仍不能精确完成任意有限段的光谱透射合成，本轮预算没有宣称已经解决体积渲染。

## 复现与校验

```powershell
cargo run --release -p sky-atmosphere-lut --example probe_single_eight_cpu -- out/lut_reference_v6 --full-probe out/lut_single_multi_rgb_warp/probe.json --out out/lut_single_multi_eight_wave
python scripts/summarize_single_eight.py out/lut_single_multi_eight_wave/probe.json
```

输出目录须不存在。CPU 运行约 6.7 秒，主要包含 8 个源波段的读取及多种步数对照；不是 GPU 性能数据。源模型及全部参考波段校验和会与旧的 41 波段对照核对。

`probe.json` 保存逐点 8/41 波段结果；`summary.json` 同时包含 1e-8 与 1e-4 阈值统计；`single_per_nm.f32` 保留 8 波长单次散射样本用于后续 CPU 拟合。

共享的单次积分器移到 `examples/support/frozen_direct.rs`，8 波长配置位于 `examples/support/eight_wave.rs`。几何步长测试、demo 颜色矩阵/带宽/太阳单位校验通过；两个 CPU example 的严格 Clippy 检查通过。
