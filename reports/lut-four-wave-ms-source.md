# 当前多重散射资源的来源

2026-09-18。实时默认已按用户选择改为单方向平行太阳，保留原太阳圆盘显示。MS 资源和地面辐照度不重烘焙，仍来自有限太阳的冻结 v6 参考；这与上一轮平行光误差对照的设置一致。

生成链路为：**冻结光谱辐亮度场 → CPU 入射场球谐投影 → 相位卷积 → 固定方向源纹理 → 视线积分**。

1. 读取 `out/lut_reference_v6`，检查模型指纹和波段校验和，提取已选的 450、510、580、650 nm 四个波段。输入是已经过离线多阶输运的辐亮度场，包含天空散射和地面反射，排除直接太阳圆盘。
2. CPU 对每个高度/太阳角状态查询各个入射方向，使用 64×128 角积分规则与太阳、地平线分区采样，投影到镜面对称的实余弦球谐。保留 80 个高度、193 个太阳节点；低空 16 阶、153 项，高空 2 阶、6 项。归一化系数保存为四波长 f16，亮度尺度单独保存为 f32。该合成脚本之前实测约 43 秒，不运行新的全大气多次散射迭代。
3. 第一次加载时，GPU 在球谐空间将入射场与瑞利/各气溶胶的真实相位函数卷积，并按当地物种散射系数加权。得到局部方向源：

   `J_ms(x,v,λ) = Σ_k σ_s,k(x,λ) ∫ p_k(v·ω,λ) L_ref(x,ω,λ) dω`

   这表示已经从天空或地面来的光，在当前位置再次向观察方向散射的贡献。直接太阳的一次散射由实时路径独立计算。实际命中地面时的边界亮度另取参考地面辐照度。
4. 为避免每个积分步重新展开 153 项，将 0–35 km 的卷积结果采样为 **40 高度 × 193 太阳角 × 24 太阳夹角 × 8 绕太阳锥角** 的 RGBA16F 纹理。四通道是四个波长；纹理存归一化源形状，查询时恢复 f32 亮度尺度与当地总散射系数。高于 35 km 的固定介质没有气溶胶，保留六项 SH 即可做瑞利卷积。初始化后释放完整低空 SH。

低空方向纹理为 11,857,920 B，高空 SH 为 379,824 B。亮度尺度、介质等辅助数据另有 337,200 B。加上太阳透射数据及 SkyView，常驻总量仍为 15.992 MiB。

因此，实时 MS 查表的含义是“当前位置、当前方向的间接散射源有多强”，不是“这个像素的最终天空有多亮”。沿视线还要计算 `∫ T J_ms ds`，才能得到天空或有限线段散射。太阳时间、高度和观察方向均在资源的坐标域内，改变它们不必重新求解 MS。

这份资源继承冻结参考的偏差，并增加球谐截断、量化、重采样误差；它没有在压缩表示中重新迭代到另一个自洽解。当前的平行太阳简化只作用于运行时直接一次散射，间接场仍沿用原参考。后续可直接将加载时的卷积与展开移到离线导出，数学内容不需要改变。

实现：`examples/export_four_wave_cpu.rs` 负责 CPU 合成；`src/four_wave/runtime.wgsl` 的 `indirect` 实现 SH 相位卷积；`src/four_wave/cache.wgsl` 的 `build_ms` 展开固定纹理，`indirect` 查询该纹理。
