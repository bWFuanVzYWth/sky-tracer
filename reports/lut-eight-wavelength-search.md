**数据、目标和误差口径**

参考源是 `out/lut_reference_v6` 的 41 个 380–780 nm、间距 10 nm 的积分光谱带；模型指纹 `18e1e068af347c04`。数据集记录每个源波段的校验和，搜索与参数导出都检查来源一致性。旧 demo 仅作为基线，其色彩转换读取实际 WGSL 常数，避免用另一套舍入的颜色矩阵冒充旧结果。

CPU 对 180,480 条光线计算每个波段的总天空 LUT 值 `L`、单次散射 `S` 和地面边界 `B`。直接项使用当前冻结大气的完整高度剖面、四类气溶胶的测量相位、256 步和 4×16 有限太阳盘采样；地面边界使用 LUT 中的总辐照度。太空光线先求大气入口。物理计算、特征、SVD 拟合和候选积分均为 f32。

训练 7,680 条光线、216 个时间/高度姿态，验证 6,912 条、198 个姿态；高度范围覆盖 3 m 到 12,000 km。太阳采样除了固定高度角，还围绕各高度的局部几何地平线布点。训练包含近太阳、日间、日落、蓝调、高空地影、上层/太空和日间地面七类区域。独立验证改变了高度、太阳高度、相对方位及近太阳角距。

用 `Wλ` 表示当前 41 带到 Rec.2020 的积分颜色基，用 `q_i / Δλ_i` 缩放选中波段：

```
D41 = Σλ (Sλ + Bλ) Wλ
D8  = Σi (Sλi + Bλi) Wλi (qi / Δλi)
E   = ||D8 − D41||₂ / max(||L41||₂, 1e−7)
Lpreview = L41 + D8 − D41
```

统计只保留 `||L41||₂ > 1e−8` 的样本，并额外保存 `>1e−4` 的较亮样本指标。因此小于 1e−7 的极暗样本使用归一化下限；这些百分比不是不加限制的相对误差上界。优化中还分别拟合 S 和 B，减少它们彼此抵消错误的机会。全光谱方向附加拟合总天空 L；角向方向附加相邻观察光线的误差变化。后者是离散角向差分约束，并非连续角导数或时间稳定性的证明。

预览把完整参考的间接 RGB 保持不变，单独替换 D 的光谱积分。这样不会把多重散射插值误差与波长误差的偶然抵消奖励给某个组合。预览没有直射太阳盘。显示使用 demo 的 Enhanced Reinhard（1.1）f32 移植及 sRGB 编码，曝光从每幅参考图确定，并固定用于该图所有候选；不同时间的曝光不同，不能用这些图比较一天中的绝对亮度变化。

**搜索范围与额外约束实验**

主要搜索保留八个互不重复的波长，每个共用一个正积分权重（0.2–200 nm），没有任意的八到三通道回归矩阵。三个等式约束要求候选直接太阳的 Rec.2020 与完整参考一致，保留原来的全光谱太阳到 D65 变换。导出的六组参数对太阳白点的最大相对残差不超过 1.8e−7。

五类拟合目标分别从 128 个起点执行单波长交换局部搜索，共 661,864 次“组合/目标”评估，涉及 496,849 个不同组合；每类保留 64 项进入验证。`C(41,8)=95,548,245`，本次不是穷举，也不声称全局最优。新组合搜索保留内部正权重解；旧波长的约束拟合额外枚举活跃边界，防止它因为无约束解含负权重而被跳过。

先做了权重总和固定 410 nm 的搜索，随后比较解除此约束的版本。固定总和的部分解需要把 130–157 nm 权重放在 380/390 或 720–740 nm 的低可见贡献位置；对当前目标而言，它消耗自由度来满足一个额外的标量积分条件。解除总和约束后仍保留正权重、太阳 RGB、全光谱教师和原色彩变换，验证最差区域表现改善，旧波长单独重拟合也有明显收益。

这不意味着权重总和是一般光谱积分中的无用约束；这里优化的是固定大气、太阳光源和观察器下的可见颜色积分。未证明这些权重适合任意光源或窄带光谱。[固定 410 nm 的对照搜索](C:/WorkSpace/sky_tracer/out/wavelength_search_final/search.json)和[对比页](C:/WorkSpace/sky_tracer/out/wavelength_search_final/visual/index.html)保留用于复核。两个目录的 C1–C6 编号各自独立；本文主要表格和推荐均使用 `wavelength_search_free_span`。

**复现与验证**

全部工作在 CPU 完成，没有启动新的 GPU 烘焙。41 波段样本生成约 359.7 秒（16 线程），主要候选搜索约 22.5 秒；搜索只需复用约 89 MB 的三份光谱数组，无需再次读取/烘焙整个参考 LUT。


这些命令要求新输出目录；已有结果不需要重跑。数据导出例程的两个已有支撑测试通过，两个新增 Rust 例程通过严格 clippy；检查了训练/验证/图像的姿态隔离、所有导出表的尺寸/有限值、太阳白点一致性。对比页的场景切换、候选切换、闪烁和本地文件链接通过 72 组组合的脚本执行检查。已检查生成的 PNG 联系表；未运行 GPU 计时或改变 demo 默认组合。
