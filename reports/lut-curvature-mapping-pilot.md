# 参考派生源的曲率分配与低成本坐标拟合

2026-09-19。完成 CPU 可行性实验，未启动 GPU、未重新烘焙参考、未修改 demo 或混合求解器默认映射。目标是保持现有 48 高度、177 太阳状态、24 太阳夹角、8 锥角预算，同时降低插值误差；不是增加运行时解码工作。

## 结论与验证范围

**可以用参考数据指导分配，但曲率应作为初始化/先验，最终仍用实际插值误差选择简单映射。** 固定节点预算下，当前实验的海拔、太阳角、锥角都有明显收益。太阳夹角收益较小，保留已有函数形状，只调整两个权重。

先使用 943,624 个样本拟合/筛选，再冻结参数，对整体移动后的高度、太阳角、方向组合生成 1,885,704 个新样本，并将曲线采样密度翻倍。后者没有参与参数搜索。模型、四波长和地面反照率未变。

下面是第二套新采样上下文上的 **单轴、四波长局部源相对误差**，不是最终天空图像误差：

|轴|节点数|原映射 P95|候选 P95|原映射 RMS|候选 RMS|
|---|---:|---:|---:|---:|---:|
|海拔|48|1.0835%|0.4382%|1.3254%|0.2312%|
|太阳高度|177|0.2042%|0.0948%|0.1022%|0.0477%|
|太阳夹角|24|0.6247%|0.5675%|0.3008%|0.2807%|
|绕太阳轴锥角|8|1.3795%|0.7660%|0.6166%|0.3547%|

测量对象是 `shape * exp(log_mean)`，即除去当地总散射系数后的四波长源。对每条曲线，以自身峰值的 1e-5 作为暗部相对误差下限/有效点筛选，并排除极暗的整体状态。恢复当地散射系数不改变各波长单独的点相对误差，但会重新加权四通道向量误差；表中没有做这一步，也没有乘路径透射/积分权重。统计按导出曲线采样分布计数，不是均匀立体角或用户镜头出现频率的加权结果。四轴误差不能直接相加。

教师是 `out/four_wave_source_v1`：冻结 v6 参考投影出的低空 SH16、高空 SH2，并使用已有 f16 系数和高度/太阳插值。因此这些结果证明的是**简单映射优化的可行性**，还不是对原始参考卷积、任意大气参数、四维联合插值或完整输运迭代的精度保证。不能把这里的 0.44% 等数值称为天空总误差。

## 曲率如何使用

对一维分段线性插值，局部误差近似 `|f''(x)| * dx² / 8`。等局部误差分配给出节点密度 `rho(x) ∝ sqrt(|f''(x)| / tolerance(x))`。如果目标是加权积分平方误差，理论指数不同：`rho ∝ (w * |f''|²)^(1/5)`。两者都依赖误差度量和采样权重，不存在直接对原始 RGB 二阶差分即可得到通用最优分配的结论。

当前表将归一化形状 S 与对数亮度 g 分开插值，因此本实验使用的海拔曲率误差项是：

`exp(g) * [S'' + S * g''] * dx² / 8`

不是直接计算完整辐亮度或 `S*exp(g)` 的曲率。后者包含本插值器不会产生的交叉导数项，完整辐亮度还会受到已经由实时单散射处理的尖峰支配。

对训练上下文做相对尺度归一化、取曲率的 85 分位数并平滑；与旧分配密度混合，避免噪声、参考网格折点或少数极暗样本耗尽预算。海拔选择出的混合比例为 70% 曲率先验、30% 原先验。1、2、11、12、35 km 的已知介质分界作为固定节点。其余三个轴不直接存任意曲率 CDF，而在受运行时成本约束的函数族中用实际插值误差搜索参数。

## 四个候选及运行时成本

### 海拔：只改 48 个常量

保持 24 个低空节点及 25 个高空节点，共享 35 km 边界；低空纹理大小不变。任意新节点都在离线求出，运行时继续用原有的高度二分和物理高度线性插值，不增加每次查询计算量。

前几个高度由 `0, 1.1, 5.9, 18.4, 45.3, 99.2, 201 m` 改为约 `0, 10.2, 85.2, 337.6, 1000 m`，释放的节点主要分配给 1–2 km、介质分层以及 35 km 附近。完整列表见拟合 JSON。源已除去当地散射系数，不需要照搬完整天空的近地面密度分配。

### 太阳高度：保持海拔耦合，替换反正切 CDF

仍以该海拔的几何地平线仰角 `eh` 为中心，使用 `eh`、`eh-6°`、`-eh` 三个中心。将 `atan(d/w)` 换成简单 softsign：

`R(d,w) = d / (abs(d) + w)`

每个分量在 [-90°,90°] 归一化，叠加线性底和原有天顶 cap。拟合权重为：线性 0.05395，地平线 0.53260，暮光 0.31437，镜像地平线 0.02283，天顶 0.07626。三个宽度（弧度）为 0.15660、0.11525、0.25173。

各高度层的中心、归一化幅度和偏置在初始化时合并为常量。运行时一个太阳仰角 `asin(mu_s)` 在相邻两高度查询间共享，再计算三个有理式和原有 cap；**不再需要 `atan`，不在查询路径反解 CDF**。参数拟合、节点反解都在 CPU 离线或初始化中完成。几十层常量为几 KiB 量级，可放入现有辅助缓冲；没有新增纹理采样或更高维查表。

只用太阳余弦、完全去掉端点加密的更简公式曾使误差上升，已排除。这里保留必要的端点分配，不以破坏质量换少一个函数。

### 太阳夹角：保留公式，只改权重

`u = 0.61 * acos(nu)/pi + 0.39 * cbrt((1-nu)/2)`

原权重为 0.5/0.5。运行时函数数量完全不变。尝试过只用余弦的单有理式，以及弦长有理式；前者在极点损失明显，后者部分统计改善但 RMS 不够稳定，未选入最终候选。这个轴目前没有足够收益来支持更复杂的分片或条件映射。

### 锥角：去掉 acos，使用小多项式

`c = (1-cos(psi))/2`

`u = c + 0.1642857 * c*(1-c)*(2*c-1)`

原查询已经从 `(mu,mu_s,nu)` 得到 `cos(psi)`。新映射省去 `acos`，只增加几次乘加；严格单调，保持 0 和 1 两端，硬件线性插值和查询次数不变。密度从锥角两端移向中段，较符合当前局部源随垂直方向变化的形状。

上述是操作数量/数据布局比较，**没有测量新 shader 的 GPU 帧耗时**。特别是除法与反三角函数的实际代价需要编译后的 shader 计时，不能直接据此承诺多少毫秒。

## 实施边界与后续验证

映射参数固定；运行时不计算曲率、不做拟合、不求导、不运行迭代反解，不引入神经网络或多项级数重建。首选沿用硬件插值和已有数据访问结构。介质改变时可先复用这套映射重新求解，但精度保证仍只覆盖训练介质；固定参数的大气最适合该策略。

正式接入前应先从原始冻结参考直接卷积抽检候选的关键源值，排除 SH 截断/量化给出的假收益；再固定角积分和迭代次数，比较旧映射与候选的真实四维联合插值、有限线段及天空输出。重点扫描正午地平线、太阳附近、日落和移动地影。高空入射方向积分的欠采样是另一个误差来源，源 LUT 坐标优化不能替代它。

本轮已完成：f32 单调性/端点/反解往返检查、仿射曲线插值检查、固定低空节点预算检查、Rust 生成器实际运行、训练外上下文检查。未把候选标成生产默认。

## 文件与复现

- CPU 导出：`crates/sky-atmosphere-lut/examples/mapping_curves_cpu.rs`
- CPU 拟合：`scripts/fit_hybrid_mapping_cpu.py`
- 最终候选及初轮统计：`out/hybrid_mapping_fit_v4/fit.json`
- 新上下文统计：`out/hybrid_mapping_check_v1/check.json`
- 分配曲线：`out/hybrid_mapping_fit_v4/mapping_allocation.png`

```powershell
cargo run --release -p sky-atmosphere-lut --example mapping_curves_cpu -- --out out/mapping_curves_new
python scripts/fit_hybrid_mapping_cpu.py out/mapping_curves_new --out out/mapping_fit_new --solar-nodes 177
cargo run --release -p sky-atmosphere-lut --example mapping_curves_cpu -- --out out/mapping_curves_check_new --shifted-validation --sample-multiplier 2
python scripts/fit_hybrid_mapping_cpu.py out/mapping_curves_check_new --out out/mapping_check_new --check-fit out/mapping_fit_new/fit.json
```

输出目录必须不存在，避免覆盖旧实验。物理源采样、场数据和插值误差评价为 f32；SciPy 参数管理、统计量以及 NumPy 节点一维重采样内部可用 f64，生成的节点和每次映射评价参数转换为 f32，不改变烘焙器或运行时精度。
