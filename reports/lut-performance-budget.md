# 混合大气 LUT：性能预算与简化审计

2026-09-19。接续[重要性求积与去重](lut-importance-and-performance.md)。本轮按“质量已达到预期，允许轻微劣化，性能优先”收敛，已接入 `Config::balanced()` 和 demo 的 `hybrid-4d`。参考烘焙器、冻结光谱数据、四波长组合及物理相位函数不变。

## 实测结果

|项目|此前配置|当前配置|
|---|---:|---:|
|启动求解中位数，RTX 4090|1.617 s|**0.393 s，快 4.12 倍**|
|常驻载荷，含 SkyView|13.001 MiB|**7.910 MiB**|
|求解峰值载荷|1013.65 MiB|**44.194 MiB**|
|太阳高度变化，demo GPU 时间|0.313 ms|**0.239 ms，减少约 24%**|
|仅相机变化，demo GPU 时间|0.0133 ms|0.0133 ms|
|完全复用，demo GPU 时间|0.00512 ms|0.00512 ms|

启动采用新旧交替、各六次测量：旧范围 1.615–1.645 s，新范围 0.391–0.396 s，记录见 `out/hybrid_budget_v1/production_timings.json`。耗时包含求解调度、GPU 执行与等待，不含设备／管线创建。阶段时间戳不含方向预计算，因此判断总体收益使用完整 wall time。

demo 为同一 RTX 4090 / Vulkan、512×384 输出、4 次预热后 32 次测量，GPU 时间包含展示 pass。旧记录在 `out/hybrid_perf_v1/demo_noon.json`，新记录在 `out/hybrid_budget_v1/demo_noon.json`；运行时新旧没有像启动一样做六轮交替。新太阳更新 P95 为 0.241 ms。上述显存是资源载荷统计，不含驱动分配和输出目标；不是进程显存占用的上限。

## 最终分配

|参数|此前|当前|取舍|
|---|---:|---:|---|
|源项高度|48|40|保留物理剖面锚点和拟合坐标|
|太阳高度|176|160|继续保持 16 对齐|
|出射相位 × 绕轴角|24×12|20×12|保留较敏感的 12 个绕轴节点|
|各图表入射求积，极向 × 半球方位|40×32|32×16|所有高度使用同一方位规则|
|启动路径步数|96|64|保留原有连续高度步进映射|
|多重散射迭代|8|8|蓝调时刻对少迭代更敏感|
|光学深度表|256×1024|128×512|RGBA16F；拟合坐标不变|
|光学深度积分步数|1024|256|单独缩减对最终天空影响很小|
|SkyView|256² RGBA32F|不变|防止薄边缘插值和量化误差叠加|
|运行时路径步数|128|96|太阳／海拔变化时生效|
|临时入射数据高度批大小|全部高度|4|纯调度变化，降低峰值显存|

源项仍为四维的局部多重散射源，不包含运行时直接单散射。四个波长为 450、510、580、650 nm；输运计算和累积用 f32，低空归一化源项与光学深度存 f16，其余原有 f32 资源保持不变。大气／反照率变化才重算源项；太阳高度／海拔变化只更新 SkyView；相机旋转和太阳方位变化只重投影。

批处理复用入射辐亮度、方向和矩缓冲。每轮所有批次都读取同一个上一轮源项／地面场，写入下一轮互不重叠的高度行，地面边界只更新一次。没有把高度切成独立求解区域，也没有在插值中加入批边界。旧尺寸下，整高度与 2／4／8 高度批次的 43 个图像输出逐 bit 相同。方向每批重新准备，增加少量重复计算，但显存收益足够大。临时资源及备用迭代场在求解结束后释放。

## 质量代价

测试包含 43 个基础视图、222 个独立扫描、48 个高空留出视图，再加 112 个掠角视图，共 **425 个标准大气视图**。掠角视图再用 **4 倍气溶胶密度**重算，合计 **537 个场景／介质组合**。

掠角测试高度 2 m、20 m、200 m、1 km；太阳高度 −8°、−6°、−1°、−0.1°、0.1°、1°、47°、85°；朝向太阳、侧向、背向；使用地平线附近 512×24 横条及额外的 128² 近太阳视图。这些测试用于发现高密度长路径的条纹、圆环、漏光和积分退化。检查的近太阳、正午及蓝调图像未见明显新增圆环；数值残差有所增加，不能据此宣称所有视图都无伪影。

指标为线性 Rec.2020 三分量向量差的相对百分比，分母下限 `1e-7`，参考范数大于 `1e-8` 的像素参与统计。先计算每图 P95，再取整个集合的最大值。求解误差使用直接积分输出，另行统计 SkyView 插值差异。

|对加密诊断解的差异：最坏图像 P95|此前|当前|
|---|---:|---:|
|313 个一般／高空视图|0.992%|2.418%|
|112 个近地掠角视图|0.924%|1.163%|
|112 个四倍气溶胶掠角视图|3.703%|4.103%|

一般集合的最坏视图位于 72 km 地球阴影附近；普通掠角最坏视图为 1 km、太阳 −8°、背向太阳。两个集合并不表示“所有常见场景误差增加到 2.4%”。几个基础场景如下：

|视图|此前对加密解 P95|当前对加密解 P95|
|---|---:|---:|
|正午太阳附近|0.044%|0.041%|
|正午地平线|0.095%|0.172%|
|太阳 5° 近景|0.019%|0.028%|
|太阳 47° 近景|0.022%|0.041%|
|蓝调，朝向太阳|0.396%|0.414%|
|蓝调，背向太阳|0.509%|0.551%|
|飞机高度暮光|0.411%|0.682%|

加密诊断使用 64×64 入射求积、192 步路径积分、12 次迭代、256 步运行时积分，并保留此前 48×176×24×12 源项网格。其中一般集合使用实验方位高斯求积，掠角集合使用均匀方位；均包含实验材料边界切步。它们是更密的有偏收敛探针，**不是物理真值，也不能隔离共享源项网格的误差**。对冻结完整光谱参考的原有高空差异仍存在（上层薄边缘和轨道暮光 P95 约 30%／16%），本轮没有解决或归因这些差异。

SkyView 相对同配置直接积分：313 视图最坏 P95 为 1.121%，近地掠角 0.298%，四倍气溶胶 0.299%；极薄边缘仍存在较大的单像素尾部，全部测试最大约 12.5%。保留 256² 和 f32 是为了避免这里继续叠加退化。横向相邻像素残差梯度的最坏 P99，普通掠角由 0.070% 增到 0.145%，四倍气溶胶由 0.069% 增到 0.144%；这是数值平滑性探针，不是视觉阈值。

光学深度单独用实际 GPU RGBA16F 表，与 8192 步 CPU f32 光学积分比较 33,410 条路径。当前透射率相对差异 P95 为 0.238%、P99 为 0.474%（统计 T>1e−4），最大绝对差 0.00236；T>0.1 时最大相对差 0.706%。此前分别为 0.163%、0.335%、0.000715、0.248%。CPU/GPU 算术和插值差异也包含在内。光学表缩减单独对基础天空的最大场景 P95 变化约 0.087%，减少光学积分步数约 0.046%，收益／代价合适。

## 简化审查

以下实验已从正式实现删除，而不是留下一组默认关闭的分支：

- 新的方位高斯求积及高低空两套规则：全高度高斯 24 节点在掠角集合对加密解的最坏 P95 为 1.089%，同阶段均匀 32 节点为 0.709%。只在高空启用带来的收益不足以保留额外规则。最终沿用原有极向高斯节点和统一方位节点，未增加新的高斯方位算法。
- 在路径上插入材料层边界或太阳阴影交点：对少数场景有改善，但没有稳定的整体收益；阴影交点的最大场景 P95 改变量仅约 0.045%。保留原来的固定次数、连续高度集中步进。
- 首阶单散射缓存：较小配置下缓存约 1.032 s，不缓存约 0.98 s，已无稳定速度收益且占用更多显存。删除字段、绑定、缓冲及 shader 分支。
- SkyView f16：只省 0.5 MiB，量化的最大场景 P95 变化约 0.82%，不采用。
- 太空弦长归一化和额外薄边缘权重：收益不稳定，会把误差转移到别处，不采用。

保留原有的简单、收益明确的优化：反射对称、四物种共享相位索引、固定高度系数、零间接场首轮跳过、常量特化，以及 35 km 以上精确 Rayleigh 二次型。已有的太阳图表权重在 12–35 km 连续衰减仍保留：删掉后高空阴影收敛更差且略慢；它只是同一积分的平滑分区权重，不引入新的分层求解。原有地平线三次坐标也保留。

单轴筛选中还检查了更激进的降采样：绕轴 12→8 的最大图像 P95 改变约 1.15%；极向 40→24 为 3.48%；迭代 8→6 为 1.51%，8→5 为 3.77%；运行时 128→64 在旧网格飞机场景为 1.59%，与其它缩减组合后高空可到约 3.8%。这些差异不能线性相加。最终保留 12 个绕轴节点、32 个极向节点、8 次迭代和 96 步运行时积分，避免集中在暗部的退化继续叠加。

## 验证与复现

已通过 3 个库测试（映射／配置／WGSL 验证）、examples 与 demo 的 release 构建，以及真实 GPU 的最终场景集和 demo 快照。`validate` 验证太阳／相机变化不重算介质，物理参数变化实际改变源项，真空为 L=0/T=1；六组有限段组合验证最大辐亮度相对差 0.00219%、透射率绝对差 5.25e−6。
