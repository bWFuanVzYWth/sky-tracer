# v5 全谱参考资源：CPU 质量验收

2026-09-14。结论：**可以用于合成管线与压缩方法的实验，但不通过“任意时间、任意海拔”的高精度合成基准验收。** 已检查的地面日间场景明显改善；高空掠日几何仍有严重错误，暮光也存在可分辨的稳定偏差。现在进行全域生产拟合，会把这些误差一并固化。

本次仅使用 CPU：读取和校验已烘焙资源、查询光谱、积分 Rec.2020、复用已有 PT / UE 输出、计算确定性输运残差。没有重新烘焙、运行 GPU 测试、启动 demo 或改动求解器。

## 完整性与合成通路

- 资源：`out/lut_reference_v5c`，41/41 波段，均完成 16 阶，实际共 **21,082,768,577 bytes**。
- 全部文件的长度、校验和、有限性和非负性通过。模型指纹 `18e1e068af347c04` 与当前输入一致。
- 最后一阶的最大相对峰值增量为 **0.00146%**，最大相对纹素和增量为 **0.00613%**。这是全域聚合量，不能当作暗部误差上界，也不能证明坐标和积分已收敛。
- 使用正式 `synthesize` 接口生成 **1,814,226 个 Rec.2020 查询**，覆盖 8 个已有对照视图、144 条观察方向曲线、18 条太阳高度扫描，耗时 **26.42 秒**，包含全谱文件读取 / 校验及输出。所有结果有限。
- 合成顺序是逐波段查表，再积分颜色，保留 f32 和当前光谱精度。没有把 RGB 大表重新插值来冒充光谱参考。

## 高空掠日异常：阻止全域验收

固定视线在当地地平线上 0.1°、方位朝太阳，只改变太阳高度：

- 120 km，太阳由 -11.02° 到 -11.00°，合成 Rec.2020 亮度从约 **2.2745 降到 0.5228**，相邻 0.02° 查询下降 **77.0%**。
- 30 km，太阳约 -5.7° 至 -5.5° 之间出现窄的峰谷；不是仅在几乎全黑处的巨大相对误差。

这可能发生在随时间变化的日出 / 日落，也会影响太空视线的大气入口。只有地面太阳高度 0°、20°、85° 等固定快照，无法覆盖这类局部几何。

为区分物理锐边和插值缺陷，重新计算冻结参考场的输运方程右端：

```
L_rhs = 直接太阳产生的单次散射
      + 沿视线积分 [相位 × 已存总辐亮度的全方向积分]
      + 透射后的地面边界项
残差 = L_stored / L_rhs - 1
```

它不修改参考表，也不是新的全局解。它复用消光表和已存入射辐亮度，用更细的 CPU 射线 / 球面积分检查自洽性。误差可能通过多次散射传播，不能把该残差直接当作相对真实解的误差。

在 1024 步射线、双 64×128 入射规则、8×32 太阳盘积分下：

| 海拔 / 太阳 / 波段 | 存储值相对方程右端的残差 |
|---|---:|
| 120 km / -11.00° / 550 nm | **-67.15%** |
| 120 km / -11.00° / 680 nm | **-85.67%** |
| 120 km / -10.98° / 680 nm | **-90.99%** |
| 30 km / -5.64° / 550 nm | **+130.51%** |
| 30 km / -5.64° / 680 nm | **+504.29%** |

例如 120 km / -11.00° 的 550 nm：表内总辐亮度为 0.02845，CPU 单次散射为 0.07514，加上间接项的右端为 0.08663。**存储的总量已经低于用同一消光表算出的单次散射分量**，不能把这一现象解释成正常的地球阴影形状。

对 120 km / -11.00°、30 km / -5.64°、2 km 暮光三个姿态进一步加到 **2048 射线步、双 128×256 入射方向、16×64 太阳盘**，异常仍存在：前两项的 680 nm 残差分别为 -85.67% 和 +504.49%，2 km 的 550 nm 仍为 +6.33%。因此不是验收积分本身太粗造成的大幅误判。

![高空掠日扫描与独立 CPU 射线积分](../out/lut_v5_cpu_quality/high_altitude_solar_failure.png)

异常集中在太阳、观察方向和地平线同时接近的区域，且显著依赖波长。现有证据把排查重点指向联合坐标 / 插值以及这些节点的烘焙值；尚未进一步区分这几项的贡献。本轮没有靠平滑或增大分辨率掩盖它。

## 非极端查询的输运残差

初步检查 20 个物理方向 × 440 / 550 / 680 nm，包含正午地平线、太阳附近、暮光、地面反射、30–120 km 和 400 km。把射线积分从 256 加到 512 步，入射双规则从 32×64 加到 64×128，60 个残差的最大变化为 **0.426 个百分点**。

多数常规白天测试点残差较小，但仍有需要处理的区域：

- 2 km、太阳 -6°、背日、地平线上 1°，更细积分后残差约 **+4.35% / +6.34% / +6.76%**（440 / 550 / 680 nm）；直接散射为零，问题存在于间接场 / 插值中。
- 30 km、太阳 20° 的红光点残差约 **+3.33%**。
- 400 km 背日深阴影，几个波段约 **-2% 至 -4.6%**，但绝对辐亮度极低，且现有 PT 无法验证该场景。

这些结果说明只看最后一阶的全域增量，无法判断暮光和高空是否已足够准确。

## 对合成数据的使用决定

1. **允许用于开发实验**：正式 CPU 合成通路已经验证，可生成有来源记录的样本，研究存储布局、CPU 吞吐量、重采样和压缩方法。
2. **限制精度结论**：当前地面日间验证点表现较好，但本次没有证明某个完整连续高度 / 太阳角范围全部合格，不能简单用一个高度阈值宣称“以下都可用”。
3. **暂缓全域生产拟合**：先解决高空掠日峰谷，再处理暮光地平线和 2 km 间接场残差。已发现的失败姿态、连续太阳扫描和高采样 PT 均值应保留为固定验收集，不参与压缩拟合。
4. **天空与有限线段分开验收**：当前合成的是到大气 / 地面边界的辐亮度，不含直接太阳盘。视距雾、短线段散射和动态遮挡体积光还没有完整合成与误差验证，不能仅靠天空表通过就认为这些用途也通过。

后续仍可先用 CPU 分解误差来源、做稀疏节点重算和映射试验。这个结论不要求立即启动下一轮 GPU 烘焙。
