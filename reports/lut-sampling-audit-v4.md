# v4 LUT 采样分配与剩余伪影分析

2026-09-14。本轮只分析：未改动求解器、运行时映射或已有资源，未启动新 GPU 计算。新增 CPU 诊断程序和图表，供下一轮统一调整。

结论：**主要问题是太阳轴、散射角轴与可实现方向边界的耦合，以及节点预算分配不均。** 观察方向轴和高度轴另有局部薄弱区，但不能简单按 `64×32×97×256` 的最小数字决定先加哪一维。整体 L2 改善之后，完整多重散射辐亮度的梯度仍存在与散射角切片对齐的明显周期跳变。

## 1. 剩余伪影的直接证据

对现有完整光谱 LUT 做 30,020 次密集 CPU 查询，覆盖太阳高度 60°、80°、85°、87°、89°，相对太阳方位 0°、30°、90°、180°，地平线上方 0.002°–15.002°。观察高度 200 m，波长 550 nm。

80° 和 85° 的朝日剖面中，亮度仍有周期性拐点；大部分梯度跳变与 `q_phase` 跨过整数，也就是散射角切片边界，对齐。85° 案例在地平线上方约 3.86°、4.87°、5.99°、7.20°、8.50°、9.88° 可见这种现象。并非一个平滑亮度误差就能概括。

![完整 LUT 的亮度和梯度](../out/lut_sampling_audit/noon_gradients.png)

将总辐亮度拆为已有首阶数据与其余阶数之差：在上述 85° 剖面拐点附近，归一化后的斜率变化中，多重散射部分约贡献每度 2.3%–2.7%，首阶贡献约每度 0%–1.5%。这是插值梯度变化的量度，**不是辐亮度相对误差百分比**。多重散射确实参与了残余条带，但不能据此直接认定增加角积分样本或迭代阶数就能解决。

## 2. 节点分配

![节点间距与分轴误差](../out/lut_sampling_audit/allocation_and_axis_error.png)

### 太阳轴：97 节点，仍有明显薄弱区和密度突变

200 m 高度的实际节点包括：

- 45.20°、49.80°、55.07°、61.40°：相邻间隔达到 **4.59°、5.27°、6.32°**。
- 天顶加密段从 61.40° 开始，下一点 63.05°：节点间隔突然从 6.32° 降为 **1.66°**。映射分段的密度衔接不平滑。
- 85°–90° 内有 **15 个节点**，末段约为 89.60°、89.78°、89.90°、89.97°、90°。相比中等太阳高度分配很密；这部分是否能减，必须按误差和梯度重新评估，不能直接删除。
- 蓝调段 −8.48°、−7.19°、−6.02°、−4.96° 等节点，仍有约 **1.1°–1.3°** 的间隔。只测试 −6° 很容易偏乐观，因为它恰好靠近一个节点。需要检查节点之间的任意时间。

太阳坐标以每个高度的几何地平线为中心。同一归一化太阳坐标在不同高度对应不同物理太阳方向；高度插值因此也带有太阳方向变化。单独增加天顶节点没有解决这项跨维度耦合。

### 散射角轴：256 节点对相位函数足够细，对移动的几何边界不一定够

实际散射角间距：

| 散射角附近 | 相邻节点间距 |
|---|---:|
| 0.25° | 0.067° |
| 1° | 0.087° |
| 5° | 0.203° |
| 20° | 0.625° |
| 45° | 1.232° |
| 60° | 1.505° |
| 75° | 1.434° |
| 80° | 1.117° |
| 85° | 0.540° |
| 90° | 0.093° |
| 120° | 2.175° |

用实际介质在 440/550/680 nm 的加权相位函数进行节点中点检查，最大插值误差分别约 **0.164% / 0.112% / 0.084%**。这是点相位检查，尚未进行太阳盘平均；说明当前分布对相位函数本身拟合得不错。

但烘焙的是完整辐亮度。朝日地平线对应的散射角随太阳高度移动，并不总在被强烈加密的 90° 附近。太阳 60° 时，这个边界就在约 60.45° 附近，而该处散射角间隔约 1.5°。因此“相位函数已调优”不能替代“辐亮度几何边界已解析”。

### 太阳 × 散射角 × 视线：不是三个互不相关的轴

查询会在高度、太阳、散射角的各个邻接节点，尝试重建同一条物理视线。如果目标视线落在该邻接球锥的可实现范围之外，当前实现只能投影到端点。

例如：观察高度 200 m，太阳 85°，朝日方向，地平线上方 0.002°：

- 原始查询的观察方向坐标为 **31.0，恰好是天空分支的端点**。
- 活跃邻接节点的物理视线偏移，权重平均约 **0.170°**，最大约 **0.440°**。
- 即使继续增加球锥内部观察方向节点，也无法消除那些已经被夹到端点的偏移。

此外，烘焙时不可实现的散射角会被夹到可实现区间边界。200 m 高度平面上，按全部太阳节点平均，约 **19.9% 的天空散射角索引**被这样裁剪，很多采到重复方向；太阳恰好在天顶时，球锥观察方向轴完全退化。这说明存在重分配节点的空间。这个比例不是整个文件可直接节省的字节比例，也不是压缩率承诺。

### 观察方向轴：24 个天空节点，地平线与暗部不能共用一个结论

32 个节点分为 24 个天空、8 个地面。天空采用面向地平线光程变化的非线性分布。对正午朝日边界，它不是当前首要瓶颈；许多目标方向本来就位于球锥端点。

补测 360 个中间方位视线后，亮度能量加权的观察方向轴误差仍较低，但暗部有局部欠采样：太阳 −6°、10 km 高度、相对方位 120°、地平线上方 10°，首阶的单轴误差约 **13.7%**。该点首阶直接积分约 `4.07e-6 W m^-2 sr^-1`，只占当前完整 LUT 约 **3.75%**，所以不能把 13.7% 当成最终天空误差。

这类暗部/阴影过渡会被全图 L2 掩盖，应单独设曝光或局部相对误差标准；不能据正午边界的好结果宣称 24 个天空节点在全域都足够。

### 高度轴：64 节点，近地和中高空需要分别看

高度使用 `rho=sqrt(h(2R+h))` 的等距分布，实际间隔为：

| 查询高度 | 包围节点 | 间隔 |
|---|---|---:|
| 200 m | 122.08–274.67 m | 152.59 m |
| 1 km | 0.763–1.099 km | 0.336 km |
| 2 km | 1.953–2.472 km | 0.519 km |
| 10 km | 9.881–11.008 km | 1.127 km |
| 30 km | 29.262–31.176 km | 1.914 km |
| 60 km | 58.814–61.505 km | 2.691 km |
| 100 km | 98.397–101.852 km | 3.455 km |

200 m 正午组的高度轴误差较小。但 60 km 地平线组中，单独高度轴的首阶相对 L2 达 **3.86%**，不能认为高空已充分解析。

400 km 观察者会先裁剪到 120 km 大气入口，所测太空案例高度轴几乎没有插值误差；大误差来自入口处太阳轴和散射角轴。没有必要为真空段增加一套 400 km 高度节点。

## 3. 分轴首阶实验

对 v4 做 1,134 个 CPU 探针，参考为 4096 段直接首阶积分、64 个太阳盘样本。参考复用原消光表，因此这部分实验**不包含消光表自身的误差**。

分轴测试把该轴的两个端点辐亮度改为直接积分值，其他轴保持连续，并保留生产查询的物理方向投影。高度轴测试包含其引起的太阳坐标变化。每列是独立实验，**不能相加，也不是完整求解器误差的线性分解**。

下表是所选点集的相对 L2，非均匀立体角采样，不是全域质量保证；均为 550 nm 首阶：

| 点集 | 高度轴 | 观察方向轴 | 太阳轴 | 散射角轴 | 256 段直接积分 |
|---|---:|---:|---:|---:|---:|
| 200 m，60°–90° 太阳，地平线上方 ≤3° | 0.132% | 0.006% | **1.492%** | 0.580% | 0.012% |
| 200 m，−12° 至 −2° 太阳 | 0.915% | 0.070% | **4.560%** | 1.469% | 0.114% |
| 近太阳视线 | 0.238% | 0.011% | **0.592%** | 0.077% | 0.149% |
| 400 km 大气边缘 | 0.001% | 0.097% | **34.597%** | **10.372%** | 0.006% |
| 200 m 中间方位视线 | 0.212% | 0.076% | 0.117% | 0.029% | 0.109% |
| 60 km 中间方位视线 | 0.470% | 0.295% | **1.436%** | 0.850% | 0.005% |

同样数量的节点，对边界和内部视线的有效分辨率差异很大。对太阳轴、散射角轴和边界投影作联合调整，比把每一轴等比放大更有依据。

## 4. 消光表也存在局部欠采样

另用 169 个路径探针比较 `128×1024` 光学厚度表与 8192 段直接消光积分，包含天空和地面路径。对直接光学厚度小于 10 的 114 个探针，透射率最大相对偏差 **4.34%**。必须同时看光学厚度/透射率大小：很暗的路径也可能产生较大的相对百分比。

| 高度 / 相对几何地平线角度 | 完整表的透射率偏差 | 高度轴单独偏差 | 视线轴单独偏差 | 直接光学厚度 |
|---|---:|---:|---:|---:|
| 1 m / −0.1°，到地面 | −3.06% | −3.06% | <0.001% | 0.0307 |
| 1 km / +1°，到太空 | +4.34% | +4.40% | −0.06% | 8.5586 |
| 2 km / +1°，到太空 | −2.88% | −2.85% | −0.03% | 5.8541 |
| 100 km / +0.1°，到太空 | −2.10% | −0.07% | −2.06% | 9.0888 |

2048 段与 8192 段直接积分之间，最大光学厚度差约 `0.000343`；表查询最大光学厚度差约 `0.0425`。这些案例主要是表采样和坐标问题，而非积分步数。近地短路径与高空掠射光程需要不同的分配标准，也与后续视距雾需求直接相关。

## 5. 多重散射积分与迭代次数

当前每套球面积分为 16 个极角环、每环 32 个方位角，分别朝向太阳与视线，共 1024 个样本。环分布集中于前向，约 77°–93° 之间没有中间环；方位角步长 11.25°。它不是均匀的高角分辨率积分。

为了判断其是否为首要问题，冻结现有完整 LUT 的入射辐亮度场，仅在 CPU 上重新计算散射源项。8 个局部状态分别使用 16×32、32×32、16×64、32×64、64×128、128×256；采用 f32 补偿求和。

- 对比最高采样规则，原 16×32 的源项偏差约 **0.04%–1.53%**。
- 200 m、太阳 −6° 的朝日/背日案例约 **0.08% / 0.12%**；2 km、10 km 的蓝调案例约 **0.38% / 0.24%**。
- 64×128 与 128×256 的差在这 8 个点约 **0.006%–0.059%**。
- 单独增加极角或方位样本并非每个点都单调改善。

这只能评估**现有入射场上的角积分敏感性**，已被 LUT 丢掉的角度细节无法靠此恢复，也不是重新求出的完整多重散射解。现有证据支持先解决坐标/源场离散，再研究角积分；不能把完整解的周期拐点简单归因于 16 阶不够。全局阶增量也不能代替蓝调局部的收敛检查。

## 6. 与现有实时映射的关系

仓库 8 波长 UE 方案的 skyview 是 `256×256`，观察仰角轴直接锚定几何地平线，水平方位轴独立；它的多重散射表为 `64×64`，高度使用指数 CDF。当前 4D LUT 的 24 个天空球锥节点则依赖太阳和散射角，不能按“256 对 24”直接换算精度。

值得保留的经验是：明确锁定地平线边界，并按介质和辐亮度变化分配节点。不能把针对某个近似场调好的映射直接视为完整多阶、含相位 4D 场的误差保证。

## 7. 下一轮统一调整的优先级（本轮未实施）

1. **太阳 × 散射角 × 可实现方向边界**：先减少邻接节点把目标视线投影到其它物理方向的情形，同时控制辐亮度和一阶导数误差。
2. **太阳轴重新分配**：中等太阳高度、蓝调节点之间、天顶段衔接一起评估，不能继续只追加天顶节点。
3. **散射角轴按完整辐亮度调优**：兼顾随太阳移动的地平线和大气边缘；纯相位中点误差已较小，不能再作为唯一目标。
4. **局部高度、观察方向和消光表**：暗部阴影、60 km 以上、近地短路径、高空掠射路径分别设误差预算。避免用亮部 L2 把这些区域掩盖。
5. **最后检查角积分和阶数**：在映射修正后的场上重新做局部收敛。增大纹理、积分和阶数不应混在同一次实验中，否则无法确认收益来源。

允许采用分区或条件映射作为候选，但尚未选择实现。资源大小暂不应成为阻碍；当前已有大量边界裁剪和方向退化，先研究如何把节点预算用到有效自由度上。

## 复现与限制

```powershell
cargo run --release -p sky-atmosphere-lut --example sampling_audit
cargo run --release -p sky-atmosphere-lut --example sampling_audit -- --interior-only
cargo run --release -p sky-atmosphere-lut --example sampling_audit -- --source-and-profiles
cargo run --release -p sky-atmosphere-lut --example sampling_audit -- --tau
python scripts/analyze_lut_sampling.py
```

输出目录 `out/lut_sampling_audit` 包含所有原始 CSV、节点数组、`summary.json` 和两张图。输入为 v4 完整 550 nm 波段及已有 cap97 首阶探针；后者地面辐照度节点较少，但首阶天空路径不含地面反射项。

分析重点是几何和采样归因，不是新的全波段 PT 认证。数值输运诊断为 f32；统计和画图采用 NumPy 默认统计精度。首阶分轴实验、冻结场角积分、消光表实验各自有明确范围；不能把它们的百分比相加，或直接当作所有颜色、任意高度、有限距离体积光的最终误差。
